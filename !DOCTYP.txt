<div class="ch" id="c1"><h2>📘 기초 개념 ① — CDF와 PDF</h2><p>모든 문제의 출발점</p></div>

<div class="box bc">
  <div class="lbl">개념</div>
  <strong>CDF (누적분포함수, Cumulative Distribution Function)</strong>
  <p style="margin-top:8px">확률변수 \(X\)에 대해, <span class="hl">CDF는 "X가 x 이하일 확률"</span>을 x의 함수로 표현한 것입니다.</p>
  <div class="mb">\[ F_X(x) = P(X \le x) \]</div>
  <strong>CDF의 필수 성질:</strong>
  <ul>
    <li><strong>단조증가:</strong> \(x_1 < x_2\) 이면 \(F_X(x_1) \le F_X(x_2)\)</li>
    <li>\(\lim_{x\to-\infty}F_X(x)=0\), \(\lim_{x\to+\infty}F_X(x)=1\)</li>
    <li>오른쪽 연속(right-continuous)</li>
    <li>\(P(a < X \le b) = F_X(b) - F_X(a)\)</li>
  </ul>
</div>

<div class="box bc">
  <div class="lbl">개념</div>
  <strong>PDF (확률밀도함수) [Theorem 4.1.1]</strong>
  <p style="margin-top:8px">연속확률변수에서 <span class="hl">PDF = CDF를 미분</span>한 것입니다.</p>
  <div class="mb">\[ f_X(x) = \frac{d}{dx}F_X(x) \qquad \Longleftrightarrow \qquad F_X(x) = \int_{-\infty}^x f_X(t)\,dt \]</div>
  <strong>PDF의 성질:</strong>
  <ul>
    <li>\(f_X(x) \ge 0\) (항상 음수가 아님)</li>
    <li>\(\displaystyle\int_{-\infty}^{\infty} f_X(x)\,dx = 1\) (전체 넓이 = 1)</li>
    <li>\(\displaystyle P(a \le X \le b) = \int_a^b f_X(x)\,dx\)</li>
    <li>연속 RV에서 \(P(X = c) = 0\) → \(P(X \le c) = P(X < c)\)</li>
  </ul>
</div>

<div class="box bt">
  <div class="lbl">⭐ 시험 핵심 흐름</div>
  <p>대부분의 변환 문제는 이 두 단계로 풉니다:</p>
  <ol>
    <li>기하학적·확률적 논리로 <span class="hl">CDF \(F_Y(y) = P(Y \le y)\)</span> 를 구한다</li>
    <li>CDF를 <span class="hl">y에 대해 미분</span>하여 PDF를 구한다</li>
  </ol>
</div>

<div class="ch" id="c2"><h2>📘 기초 개념 ② — 기댓값 · 분산 · MGF</h2><p>확률변수를 숫자로 요약하는 세 가지 도구</p></div>

<div class="box bc">
  <div class="lbl">개념</div>
  <strong>기댓값 (Expected Value) [Def 4.2.1]</strong>
  <div class="mb">\[ E[X] = \int_{-\infty}^{\infty} x\,f_X(x)\,dx \]</div>
  <strong>함수의 기댓값 — LOTUS [Theorem 4.2.2]:</strong> Y의 PDF를 먼저 구하지 않아도 됩니다!
  <div class="mb">\[ E[g(X)] = \int_{-\infty}^{\infty} g(x)\,f_X(x)\,dx \]</div>
  <strong>선형성 [Theorem 4.2.1]:</strong>
  <div class="mb">\[ E[aX+b] = a\,E[X]+b \]</div>
</div>

<div class="box bc">
  <div class="lbl">개념</div>
  <strong>분산 (Variance) [Def 4.2.2]</strong>
  <div class="mb">\[ \text{Var}(X) = E\!\left[(X-E[X])^2\right] = \underbrace{E[X^2]}_{\text{2차 적률}} - \underbrace{(E[X])^2}_{\text{(1차 적률)²}} \]</div>
  <ul>
    <li>\(\text{Var}(aX+b) = a^2\,\text{Var}(X)\)</li>
    <li>⚠️ <strong>E[X²] ≠ (E[X])²</strong> — 가장 흔한 실수!</li>
  </ul>
</div>

<div class="box bc">
  <div class="lbl">개념</div>
  <strong>적률생성함수 (MGF) [Def 4.2.4]</strong>
  <div class="mb">\[ M_X(t) = E[e^{tX}] = \int_{-\infty}^{\infty} e^{tx}\,f_X(x)\,dx \]</div>
  <strong>핵심 사용법:</strong>
  <ul>
    <li>n차 적률: \(\displaystyle E[X^n] = M_X^{(n)}(0)\) (t=0에서의 n차 도함수)</li>
    <li>정규 N(μ,σ²)의 MGF: \(M_X(t)=e^{\mu t+\frac{1}{2}\sigma^2 t^2}\)</li>
    <li>지수 Exp(λ)의 MGF: \(M_X(t)=\dfrac{\lambda}{\lambda-t}\) for \(t<\lambda\)</li>
  </ul>
</div>

<div class="ch" id="c3"><h2>📘 기초 개념 ③ — 5대 핵심 분포</h2><p>시험에 직접 나오는 분포들 — 공식 암기 필수</p></div>

<table>
  <tr><th>분포</th><th>PDF f(x)</th><th>E[X]</th><th>Var(X)</th><th>MGF</th></tr>
  <tr>
    <td><strong>Uniform(a,b)</strong></td>
    <td>\(\dfrac{1}{b-a}\), \(a<x<b\)</td>
    <td>\(\dfrac{a+b}{2}\)</td>
    <td>\(\dfrac{(b-a)^2}{12}\)</td>
    <td>\(\dfrac{e^{tb}-e^{ta}}{t(b-a)}\)</td>
  </tr>
  <tr>
    <td><strong>Exp(λ)</strong></td>
    <td>\(\lambda e^{-\lambda x}\), \(x\ge0\)</td>
    <td>\(\dfrac{1}{\lambda}\)</td>
    <td>\(\dfrac{1}{\lambda^2}\)</td>
    <td>\(\dfrac{\lambda}{\lambda-t}\), \(t<\lambda\)</td>
  </tr>
  <tr>
    <td><strong>N(μ,σ²)</strong></td>
    <td>\(\dfrac{1}{\sqrt{2\pi\sigma^2}}e^{-\frac{(x-\mu)^2}{2\sigma^2}}\)</td>
    <td>\(\mu\)</td>
    <td>\(\sigma^2\)</td>
    <td>\(e^{\mu t+\frac{1}{2}\sigma^2 t^2}\)</td>
  </tr>
  <tr>
    <td><strong>Gamma(α,λ)</strong></td>
    <td>\(\dfrac{\lambda^\alpha}{\Gamma(\alpha)}x^{\alpha-1}e^{-\lambda x}\), \(x>0\)</td>
    <td>\(\dfrac{\alpha}{\lambda}\)</td>
    <td>\(\dfrac{\alpha}{\lambda^2}\)</td>
    <td>\(\left(\dfrac{\lambda}{\lambda-t}\right)^\alpha\)</td>
  </tr>
  <tr>
    <td><strong>Beta(α,β)</strong></td>
    <td>\(\dfrac{\Gamma(\alpha+\beta)}{\Gamma(\alpha)\Gamma(\beta)}x^{\alpha-1}(1-x)^{\beta-1}\), \(0<x<1\)</td>
    <td>\(\dfrac{\alpha}{\alpha+\beta}\)</td>
    <td>\(\dfrac{\alpha\beta}{(\alpha+\beta)^2(\alpha+\beta+1)}\)</td>
    <td>—</td>
  </tr>
</table>

<div class="box bf">
  <div class="lbl">공식</div>
  <strong>감마함수 Γ(α) — 외워야 하는 성질</strong>
  <div class="mb">\[ \Gamma(\alpha) = \int_0^\infty x^{\alpha-1}e^{-x}\,dx \]</div>
  <ul>
    <li><strong>재귀:</strong> \(\Gamma(\alpha+1)=\alpha\cdot\Gamma(\alpha)\)</li>
    <li><strong>정수:</strong> \(\Gamma(n)=(n-1)!\) &nbsp; 예: Γ(1)=1, Γ(2)=1, Γ(3)=2, Γ(4)=6</li>
    <li><span class="hl">감마분포 k차 적률:</span> \(\displaystyle E[X^k]=\frac{\Gamma(\alpha+k)}{\lambda^k\,\Gamma(\alpha)}\), \(k>-\alpha\)</li>
  </ul>
</div>

<div class="box bf">
  <div class="lbl">공식</div>
  <strong>지수분포 무기억성 (Memoryless Property) — 핵심!</strong>
  <div class="mb">\[ P(X > s+t \mid X > t) = P(X > s) \]</div>
  <p><strong>직관:</strong> 이미 t시간이 지나도, <span class="hl">앞으로 기다릴 시간의 분포는 처음과 똑같다.</span></p>
  <p style="margin-top:6px">예: 전화 통화가 이미 5분째 → 앞으로 얼마나 남았는지는 처음 시작과 동일한 분포</p>
</div>

<div class="ch" id="c4"><h2>📘 기초 개념 ④ — 확률변수 변환 방법</h2><p>Y = g(X)일 때 Y의 분포를 구하는 방법들</p></div>

<div class="box bc">
  <div class="lbl">방법 A</div>
  <strong>CDF 방법 (가장 일반적 — 항상 가능)</strong>
  <ol style="margin-top:8px">
    <li>\(F_Y(y) = P(Y \le y) = P(g(X) \le y)\) 계산</li>
    <li>집합 \(\{x : g(x) \le y\}\)를 X의 CDF로 표현</li>
    <li>\(f_Y(y) = \dfrac{d}{dy}F_Y(y)\) 로 PDF 획득</li>
  </ol>
  <p style="margin-top:8px">📌 비단조 함수(X², |X|, min 등)에서 주로 사용</p>
</div>

<div class="box bc">
  <div class="lbl">방법 B</div>
  <strong>단조변환 공식 (Theorem 4.1.2) — g가 순증가 또는 순감소</strong>
  <div class="mb">\[ f_Y(y) = f_X\!\bigl(g^{-1}(y)\bigr)\cdot\left|\frac{d}{dy}g^{-1}(y)\right| \]</div>
  <p>📌 예: Y=eˣ, Y=ln X, Y=tan(πX)</p>
</div>

<div class="box bc">
  <div class="lbl">방법 C</div>
  <strong>다구간 변환 (Theorem 4.1.4) — g가 구간마다 단조</strong>
  <ol style="margin-top:8px">
    <li>지지집합을 단조 구간 A₁, A₂, …로 나눈다</li>
    <li>각 구간에서 역함수 \(\phi_i^{-1}(y)\)를 구한다</li>
    <li>PDF를 더한다:</li>
  </ol>
  <div class="mb">\[ f_Y(y) = \sum_i f_X\!\bigl(\phi_i^{-1}(y)\bigr)\cdot\left|\frac{d}{dy}\phi_i^{-1}(y)\right| \]</div>
  <p>📌 예: Y=X² (x=0에서 꺾임 → A₁=음수, A₂=양수)</p>
</div>

<div class="box bc">
  <div class="lbl">방법 D</div>
  <strong>역변환법 (Theorem 4.1.3) — 랜덤 샘플 생성</strong>
  <p style="margin-top:8px">U ~ Uniform(0,1)이고 X = F⁻¹(U)로 정의하면 X의 CDF = F.</p>
  <div class="mb">\[ \text{증명:}\ P(X\le x)=P\!\left(F^{-1}(U)\le x\right)\overset{F\ \text{순증가}}{=}P(U\le F(x))=F(x) \]</div>
</div>

<div class="ch" id="c5"><h2>📘 기초 개념 ⑤ — 포아송 과정</h2><p>랜덤 도착 과정의 핵심 모델</p></div>

<div class="box bc">
  <div class="lbl">개념</div>
  <strong>포아송 과정 [Def 4.4.1]</strong>
  <p style="margin-top:8px">단위 시간당 평균 λ개가 도착하는 랜덤 과정. 세 가지 가정:</p>
  <ol>
    <li>N₀ = 0</li>
    <li>구간 (s,t]의 도착 수 \(N_t - N_s \sim \text{Poisson}(\lambda(t-s))\)</li>
    <li>겹치지 않는 구간의 증분은 독립</li>
  </ol>
  <strong style="display:block;margin-top:10px">핵심 관계:</strong>
  <table style="margin-top:8px">
    <tr><th>확률변수</th><th>분포</th><th>이유</th></tr>
    <tr><td>t까지 도착 수 \(N_t\)</td><td>\(\text{Poisson}(\lambda t)\)</td><td>정의</td></tr>
    <tr><td>첫 도착 시간 \(T_1\)</td><td>\(\text{Exp}(\lambda)\)</td><td>\(P(T_1>t)=P(N_t=0)=e^{-\lambda t}\)</td></tr>
    <tr><td>k번째 도착 시간 \(S_k\)</td><td>\(\text{Gamma}(k,\lambda)\)</td><td>독립 지수분포 k개의 합</td></tr>
  </table>

  <strong>결합 PDF와 주변 PDF [Theorem 5.1.1]</strong>
  <div class="mb">\[ f_X(x) = \int_{-\infty}^{\infty} f_{X,Y}(x,y)\,dy \qquad f_Y(y) = \int_{-\infty}^{\infty} f_{X,Y}(x,y)\,dx \]</div>

  <strong>공분산:</strong>
  <div class="mb">\[ \text{Cov}(X,Y) = E[XY] - E[X]E[Y] \]</div>

<div class="ch"><h2>📗 문제집 5 풀이 (11문제)</h2><p>확률변수의 변환과 분포 도출 — 핵심 기법 총정리</p></div>

<!-- P5-1 -->
<div class="pc" id="p51">
  <div class="ph"><div class="pn">1</div><div><div class="pt">삼각형 내 균등분포 — 거리 X의 CDF/PDF</div><div class="ps">기하학적 확률 · 유사삼각형 · CDF 미분</div></div></div>
  <div class="pb">
    <div class="box bc"><div class="lbl">핵심 개념</div>
      <p>삼각형 안에서 균등하게 점을 찍으면 <span class="hl">확률 = 넓이 비율</span>. 밑변에서 거리 x보다 먼 곳에 해당하는 영역의 넓이를 구하면 됩니다.</p>
      <p style="margin-top:6px"><strong>유사삼각형 원리:</strong> 높이 h의 삼각형에서 높이 x만큼 위의 수평선을 기준으로 위의 작은 삼각형은 원래 삼각형과 닮음. 닮음비 = (h-x)/h이므로 넓이비 = ((h-x)/h)²</p>
    </div>
    <div class="box bs"><div class="lbl">풀이</div>
      <div class="mb">\[ P(X>x) = \frac{\text{작은 삼각형 넓이}}{\text{전체 넓이}} = \frac{\tfrac{1}{2}\cdot b\cdot\tfrac{h-x}{h}\cdot(h-x)}{\tfrac{1}{2}bh} = \left(\frac{h-x}{h}\right)^2 \]</div>
      <p><strong>CDF:</strong></p>
      <div class="mb">\[ F_X(x)=1-P(X>x)= \begin{cases}0 & x<0\\1-\!\left(\dfrac{h-x}{h}\right)^{\!2} & 0\le x<h\\1 & x\ge h\end{cases} \]</div>
      <p><strong>PDF</strong> (CDF를 x에 대해 미분):</p>
      <div class="mb">\[ f_X(x) = \frac{d}{dx}F_X(x) = \frac{2(h-x)}{h^2} = \frac{2}{h}\!\left(1-\frac{x}{h}\right),\quad 0<x<h \]</div>
      <p>체크: x=0일 때 PDF = 2/h (가장 크고), x=h일 때 PDF = 0. 밑변 근처에 점이 더 많이 찍히는 직관과 일치!</p>
    </div>
    <div class="box bt"><div class="lbl">⭐ 시험 팁</div>
      <p>P(X &gt; x)를 먼저 구하고 1을 빼면 CDF. 균등분포에서는 항상 <strong>"확률 = 넓이 비율"</strong>임을 기억하세요.</p>
    </div>
  </div>
</div>

<!-- P5-2 -->
<div class="pc" id="p52">
  <div class="ph"><div class="pn">2</div><div><div class="pt">다트 — 원형 균등분포 &amp; 혼합 확률변수</div><div class="ps">원형 넓이 비율 · 혼합 CDF · 불연속 점프</div></div></div>
  <div class="pb">
    <div class="box bc"><div class="lbl">개념: 혼합 확률변수</div>
      <p><strong>혼합 확률변수:</strong> CDF에 <span class="hl">점프(jump)</span>가 있으면 이산 성분이 존재합니다. 점프 크기 = 그 점에서의 이산 확률. 점프가 있으면 연속 RV가 아닙니다.</p>
    </div>
    <div class="box bs"><div class="lbl">풀이 (a) — X의 PDF, 평균, 분산</div>
      <p>반지름 r인 원에서 균등하게 점 → 중심에서 거리 x 이내 확률 = 원의 넓이 비율:</p>
      <div class="mb">\[ F_X(x)=\frac{\pi x^2}{\pi r^2}=\frac{x^2}{r^2},\quad 0\le x\le r \implies f_X(x)=\frac{2x}{r^2} \]</div>
      <div class="mb">\[ E[X]=\int_0^r \frac{2x^2}{r^2}\,dx=\frac{2r}{3},\quad E[X^2]=\int_0^r\frac{2x^3}{r^2}\,dx=\frac{r^2}{2} \]</div>
      <div class="mb">\[ \text{Var}(X)=\frac{r^2}{2}-\frac{4r^2}{9}=\frac{r^2}{18} \]</div>
    </div>
    <div class="box bs"><div class="lbl">풀이 (b) — S = 1/X (X≤t)의 CDF</div>
      <p>S = 0 (X&gt;t), S = 1/X (X≤t)이므로 P(S=0) = P(X&gt;t) = 1 - t²/r² &gt; 0</p>
      <p>s ≥ 1/t일 때 (S ≥ 1/t ⟺ X ≤ t):</p>
      <div class="mb">\[ P(S\le s)=P(X>t)+P\!\left(\tfrac{1}{X}\le s,\,X\le t\right)=1-\frac{t^2}{r^2}+\frac{t^2}{r^2}-\frac{1}{r^2s^2}=1-\frac{1}{r^2s^2} \]</div>
      <div class="mb">\[ F_S(s)=\begin{cases}0 & s<0\\ 1-\tfrac{t^2}{r^2} & 0\le s<\tfrac{1}{t}\\ 1-\tfrac{1}{r^2s^2} & s\ge\tfrac{1}{t}\end{cases} \]</div>
      <p>s=0에서 크기 1−t²/r² 의 점프 → <strong>연속 확률변수가 아님!</strong></p>
    </div>
    <div class="box bt"><div class="lbl">⭐ 시험 팁</div>
      <p>S ≤ s를 "X &gt; t이거나 (1/X ≤ s이고 X ≤ t)"로 분해하는 것이 핵심. 두 사건이 <strong>서로소(disjoint)</strong>이므로 확률을 더할 수 있습니다.</p>
    </div>
  </div>
</div>

<!-- P5-3 -->
<div class="pc" id="p53">
  <div class="ph"><div class="pn">3</div><div><div class="pt">역변환법 (Inverse Transform Method)</div><div class="ps">U~Uniform(0,1)으로 임의 분포 생성 [Theorem 4.1.3]</div></div></div>
  <div class="pb">
    <div class="box bc"><div class="lbl">핵심 아이디어</div>
      <p>U ~ Uniform(0,1)이고 F가 순증가 CDF일 때, <span class="hl">X = F⁻¹(U)로 정의하면 X의 CDF = F</span>.</p>
      <strong>왜 성립할까?</strong>
      <div class="mb">\[ P(X\le x)=P(F^{-1}(U)\le x)\overset{F \text{ 순증가}}{=}P(U\le F(x))=F(x)\quad\because U\sim\text{Uniform}(0,1) \]</div>
    </div>
    <div class="box bs"><div class="lbl">풀이 (b) — 지수분포 시뮬레이션</div>
      <p>Exp(λ)의 CDF: F(x) = 1−e^{−λx}. F(x) = u를 x에 대해 풀면:</p>
      <div class="mb">\[ 1-e^{-\lambda x}=u \implies x=-\frac{\ln(1-u)}{\lambda} \]</div>
      <p>1−U도 Uniform(0,1)이므로: <span class="hlg">X = −(ln U)/λ ~ Exp(λ)</span></p>
    </div>
    <div class="box bs"><div class="lbl">풀이 (c) — 이산 확률변수</div>
      <p>F(k−1) &lt; u ≤ F(k)이면 X = k로 정의하면:</p>
      <div class="mb">\[ P(X=k)=P(F(k-1)<U\le F(k))=F(k)-F(k-1) \]</div>
    </div>
    <div class="box bt"><div class="lbl">⭐ 시험 팁</div>
      <p>증명 핵심: F의 <strong>순증가성</strong>이 "F⁻¹(U) ≤ x ⟺ U ≤ F(x)" 동치를 보장합니다. 이 단 한 줄의 논리를 정확히 서술할 수 있어야 합니다.</p>
    </div>
  </div>
</div>

<!-- P5-4 -->
<div class="pc" id="p54">
  <div class="ph"><div class="pn">4</div><div><div class="pt">r(u) 찾기 — 역변환법 응용</div><div class="ps">주어진 PDF로부터 역변환 함수 r(u) = F⁻¹(u) 계산</div></div></div>
  <div class="pb">
    <div class="box bs"><div class="lbl">풀이</div>
      <p>목표: \(f_X(x)=\tfrac{5x^{3/2}}{2}\) (0&lt;x&lt;1)를 갖는 X를 U ~ Uniform(0,1)에서 생성하는 r(u) 찾기.</p>
      <p><strong>Step 1 — CDF 계산:</strong></p>
      <div class="mb">\[ F_X(x)=\int_0^x\frac{5t^{3/2}}{2}\,dt=\left[t^{5/2}\right]_0^x=x^{5/2},\quad 0<x<1 \]</div>
      <p><strong>Step 2 — 역함수:</strong> u = x^{5/2}를 x에 대해 풀기:</p>
      <div class="mb">\[ x=u^{2/5} \implies \boxed{r(u)=u^{2/5}} \]</div>
      <p>검증: U ~ Uniform(0,1)일 때 X = U^{2/5}의 CDF = P(X≤x) = P(U^{2/5}≤x) = P(U≤x^{5/2}) = x^{5/2} ✓</p>
    </div>
    <div class="box bt"><div class="lbl">⭐ 시험 팁</div>
      <p>과정 요약: ① PDF 적분 → CDF 계산 → ② CDF = u 놓고 x에 대해 풀기 → ③ r(u) = F⁻¹(u)</p>
    </div>
  </div>
</div>

<!-- P5-5 -->
<div class="pc" id="p55">
  <div class="ph"><div class="pn">5</div><div><div class="pt">Y = X² (비대칭 지지집합)</div><div class="ps">X ~ Uniform(−1, 3) — y 범위별 CDF 방법</div></div></div>
  <div class="pb">
    <div class="box bc"><div class="lbl">핵심: 지지집합이 비대칭이면 구간을 나눠야 함</div>
      <p>X ∈ (−1, 3)이면 Y = X²의 범위: 0 ≤ Y &lt; 9.</p>
      <ul>
        <li><strong>0 ≤ y &lt; 1:</strong> x = ±√y 둘 다 (−1,3) 안에 있음 → 두 역상 모두 기여</li>
        <li><strong>1 ≤ y &lt; 9:</strong> x = −√y &lt; −1 (지지집합 밖!) → √y만 기여</li>
      </ul>
    </div>
    <div class="box bs"><div class="lbl">풀이</div>
      <p>\(f_X(x)=\tfrac{1}{4}\) for \(-1<x<3\).</p>
      <p><strong>0 ≤ y &lt; 1:</strong> {Y≤y} = {−√y ≤ X ≤ √y}:</p>
      <div class="mb">\[ F_Y(y)=\int_{-\sqrt{y}}^{\sqrt{y}}\frac{1}{4}\,dx=\frac{\sqrt{y}}{2} \implies f_Y(y)=\frac{1}{4\sqrt{y}} \]</div>
      <p><strong>1 ≤ y &lt; 9:</strong> {Y≤y} = {−1 &lt; X ≤ √y} (왼쪽 한계 = 지지집합 경계 −1):</p>
      <div class="mb">\[ F_Y(y)=\int_{-1}^{\sqrt{y}}\frac{1}{4}\,dx=\frac{\sqrt{y}+1}{4} \implies f_Y(y)=\frac{1}{8\sqrt{y}} \]</div>
    </div>
    <div class="box bt"><div class="lbl">⭐ 시험 팁</div>
      <p>비단조 변환에서 가장 중요한 것: <strong>역상이 지지집합 안에 있는지 항상 체크!</strong> y가 특정 값을 넘으면 역상 하나가 지지집합 밖으로 나가 사라집니다.</p>
    </div>
  </div>
</div>

<!-- P5-6 -->
<div class="pc" id="p56">
  <div class="ph"><div class="pn">6</div><div><div class="pt">|X|와 −ln|X| 의 PDF</div><div class="ps">X ~ Uniform(−1,1) — 절댓값과 로그 변환</div></div></div>
  <div class="pb">
    <div class="box bs"><div class="lbl">풀이 — Y = √|X|</div>
      <p>범위: y ∈ [0,1]. {√|X| ≤ y} = {|X| ≤ y²} = {−y² ≤ X ≤ y²}:</p>
      <div class="mb">\[ F_Y(y)=\int_{-y^2}^{y^2}\frac{1}{2}\,dx=y^2 \implies f_Y(y)=2y,\quad 0\le y\le1 \]</div>
      <p>흥미롭게도 X가 균등분포인데 √|X|는 삼각형 PDF를 가집니다.</p>
    </div>
    <div class="box bs"><div class="lbl">풀이 — W = −ln|X|</div>
      <p>|X| ∈ (0,1] → ln|X| ∈ (−∞,0] → W = −ln|X| ≥ 0.</p>
      <p>부등식 변환 주의: W ≤ w ⟺ −ln|X| ≤ w ⟺ ln|X| ≥ −w ⟺ <span class="hl">|X| ≥ e^{−w}</span> (부등호 방향 반전!)</p>
      <div class="mb">\[ F_W(w)=P(|X|\ge e^{-w})=1-P(|X|<e^{-w})=1-\int_{-e^{-w}}^{e^{-w}}\frac{1}{2}\,dx=1-e^{-w} \]</div>
      <div class="mb">\[ f_W(w)=e^{-w},\quad w\ge0 \implies \boxed{W\sim\text{Exp}(1)} \]</div>
      <p>놀라운 결과: 균등분포에 로그 변환을 하면 지수분포가 나옵니다!</p>
    </div>
    <div class="box bt"><div class="lbl">⭐ 시험 팁</div>
      <p>−ln|X| ≤ w → |X| ≥ e^{-w}: <strong>로그 불등호 방향이 반전됩니다.</strong> 이를 P(|X| ≥ e^{-w}) = 1 − P(|X| &lt; e^{-w})로 처리하세요.</p>
    </div>
  </div>
</div>

<!-- P5-7 -->
<div class="pc" id="p57">
  <div class="ph"><div class="pn">7</div><div><div class="pt">Z = min{X, Y} — 두 지수분포의 최솟값</div><div class="ps">독립 지수분포의 최솟값은 지수분포</div></div></div>
  <div class="pb">
    <div class="box bc"><div class="lbl">핵심 아이디어</div>
      <p><strong>최솟값의 생존함수 분해:</strong></p>
      <div class="mb">\[ \min\{X,Y\}>z \iff X>z \;\text{이고}\; Y>z \]</div>
      <p>독립이면 두 사건의 확률을 곱할 수 있습니다.</p>
    </div>
    <div class="box bs"><div class="lbl">풀이</div>
      <div class="mb">\[ P(Z>z)=P(\min\{X,Y\}>z)=P(X>z)\cdot P(Y>z)=e^{-\lambda z}\cdot e^{-\mu z}=e^{-(\lambda+\mu)z} \]</div>
      <div class="mb">\[ F_Z(z)=1-e^{-(\lambda+\mu)z},\quad f_Z(z)=(\lambda+\mu)e^{-(\lambda+\mu)z} \implies \boxed{Z\sim\text{Exp}(\lambda+\mu)} \]</div>
    </div>
    <div class="box bt"><div class="lbl">⭐ 시험 팁</div>
      <p>최솟값/최댓값 문제는 <strong>생존함수 P(Z &gt; z)에서 시작</strong>하세요. P(Z ≤ z)보다 훨씬 간단합니다.</p>
      <p style="margin-top:6px">일반화: 독립 Exp(λᵢ) n개의 최솟값 ~ Exp(λ₁+⋯+λₙ)</p>
    </div>
  </div>
</div>

<!-- P5-8 -->
<div class="pc" id="p58">
  <div class="ph"><div class="pn">8</div><div><div class="pt">기차 대기 시간</div><div class="ps">조건부 사건 분해 · 구간별 CDF</div></div></div>
  <div class="pb">
    <div class="box bc"><div class="lbl">상황 이해</div>
      <p>기차: 7:15, 7:30 출발 (15분 간격). X = 7:10 이후 도착 시간(분). Y = 대기 시간.</p>
      <ul>
        <li>0 ≤ X ≤ 5: 7:15 기차 탑승 → Y = 5−X</li>
        <li>5 &lt; X ≤ 20: 7:30 기차 탑승 → Y = 20−X</li>
      </ul>
      <p>따라서 Y는 항상 [0, 5] 범위입니다.</p>
    </div>
    <div class="box bs"><div class="lbl">풀이</div>
      <p>{Y ≤ y} = {5−y ≤ X ≤ 5} ∪ {20−y ≤ X ≤ 20} (두 사건은 서로소)</p>
      <p><strong>0 ≤ y ≤ 5:</strong></p>
      <div class="mb">\[ F_Y(y)=P(5-y\le X\le5)+P(20-y\le X\le20)=[F_X(5)-F_X(5-y)]+[F_X(20)-F_X(20-y)] \]</div>
      <div class="mb">\[ f_Y(y)=f_X(5-y)+f_X(20-y) \]</div>
      <p>X ~ Uniform(0,20)이면 f_X = 1/20 → f_Y(y) = 2/20 = 1/10 (균등분포!) 직관 확인.</p>
    </div>
    <div class="box bt"><div class="lbl">⭐ 시험 팁</div>
      <p><strong>어느 기차를 타는지 경우를 나눈 뒤 합산</strong>하는 것이 핵심. 두 사건이 서로소임을 확인하고 더하세요.</p>
    </div>
  </div>
</div>

<!-- P5-9 -->
<div class="pc" id="p59">
  <div class="ph"><div class="pn">9</div><div><div class="pt">Y = X² (X ~ Uniform(−2, 3))</div><div class="ps">Theorem 4.1.4 — 다구간 역함수 공식</div></div></div>
  <div class="pb">
    <div class="box bc"><div class="lbl">방법: Theorem 4.1.4 적용</div>
      <p>φ(x)=x²은 x=0에서 꺾임. (−2,3)을 두 단조 구간으로 분리:</p>
      <ul>
        <li>A₁ = (−2,0): 역함수 φ₁⁻¹(y) = −√y, 범위 y∈(0,4), |dφ₁⁻¹/dy| = 1/(2√y)</li>
        <li>A₂ = (0,3): 역함수 φ₂⁻¹(y) = √y, 범위 y∈(0,9), |dφ₂⁻¹/dy| = 1/(2√y)</li>
      </ul>
    </div>
    <div class="box bs"><div class="lbl">풀이</div>
      <p>f_X(x) = 1/5 for x∈(−2,3).</p>
      <p><strong>0 &lt; y ≤ 4:</strong> −√y ∈ (−2,0) ✓, √y ∈ (0,2) ⊂ (0,3) ✓ → 두 항 모두 기여:</p>
      <div class="mb">\[ f_Y(y)=\frac{1}{5}\cdot\frac{1}{2\sqrt{y}}+\frac{1}{5}\cdot\frac{1}{2\sqrt{y}}=\frac{1}{5\sqrt{y}} \]</div>
      <p><strong>4 &lt; y &lt; 9:</strong> −√y &lt; −2 (A₁의 역상이 지지집합 밖!) → √y만 기여:</p>
      <div class="mb">\[ f_Y(y)=\frac{1}{5}\cdot\frac{1}{2\sqrt{y}}=\frac{1}{10\sqrt{y}} \]</div>
    </div>
    <div class="box bt"><div class="lbl">⭐ 시험 팁</div>
      <p>y &gt; 4에서 −√y &lt; −2 → A₁의 역상이 지지집합을 벗어납니다. <strong>각 역상이 원래 지지집합 안에 있는지 반드시 확인!</strong></p>
    </div>
  </div>
</div>

<!-- P5-10 -->
<div class="pc" id="p510">
  <div class="ph"><div class="pn">10</div><div><div class="pt">Y = (X−1)² (X ~ Exp(1))</div><div class="ps">지수분포에 비단조 변환 — 구간 분할</div></div></div>
  <div class="pb">
    <div class="box bs"><div class="lbl">풀이</div>
      <p>φ(x) = (x−1)²은 x=1에서 꺾임. X의 지지집합 (0,∞)를:</p>
      <ul>
        <li>A₁ = (0,1): 역함수 φ₁⁻¹(y) = 1−√y, 범위 y∈(0,1)</li>
        <li>A₂ = (1,∞): 역함수 φ₂⁻¹(y) = 1+√y, 범위 y∈(0,∞)</li>
      </ul>
      <p><strong>0 &lt; y ≤ 1:</strong> 1−√y ∈ (0,1) ✓, 1+√y ∈ (1,∞) ✓ → 두 항 기여:</p>
      <div class="mb">\[ f_Y(y)=e^{-(1-\sqrt{y})}\cdot\frac{1}{2\sqrt{y}}+e^{-(1+\sqrt{y})}\cdot\frac{1}{2\sqrt{y}}=\frac{e^{-1}}{2\sqrt{y}}\!\left(e^{\sqrt{y}}+e^{-\sqrt{y}}\right) \]</div>
      <p><strong>y &gt; 1:</strong> 1−√y &lt; 0 (지지집합 밖!) → 1+√y만 기여:</p>
      <div class="mb">\[ f_Y(y)=e^{-(1+\sqrt{y})}\cdot\frac{1}{2\sqrt{y}}=\frac{1}{2\sqrt{y}}e^{-\sqrt{y}-1} \]</div>
    </div>
    <div class="box bt"><div class="lbl">⭐ 시험 팁</div>
      <p>y &gt; 1이면 1−√y &lt; 0 → X의 지지집합 (0,∞) 밖 → 그 항은 0. 지지집합 체크 습관화!</p>
    </div>
  </div>
</div>

<!-- P5-11 -->
<div class="pc" id="p511">
  <div class="ph"><div class="pn">11</div><div><div class="pt">코시 분포 (Cauchy Distribution)</div><div class="ps">Y = tan(πX), X ~ Uniform(−1/2, 1/2)</div></div></div>
  <div class="pb">
    <div class="box bc"><div class="lbl">필요 공식</div>
      <p>tan은 (−π/2, π/2)에서 순증가. Y=tan(πX)의 역함수: X = (1/π)arctan(Y)</p>
      <div class="mb">\[ \frac{d}{dy}\arctan(y)=\frac{1}{1+y^2} \]</div>
    </div>
    <div class="box bs"><div class="lbl">풀이 (a) — 단조변환 공식 적용</div>
      <p>f_X(x) = 1 (Uniform(−1/2,1/2)):</p>
      <div class="mb">\[ f_Y(y)=f_X\!\!\left(\tfrac{1}{\pi}\arctan y\right)\cdot\left|\frac{d}{dy}\tfrac{1}{\pi}\arctan y\right|=1\cdot\frac{1}{\pi(1+y^2)}=\boxed{\frac{1}{\pi(1+y^2)}},\quad -\infty<y<\infty \]</div>
      <p>이것이 <strong>코시 분포 (Cauchy Distribution)</strong>입니다. 특이하게도 기댓값이 존재하지 않습니다!</p>
    </div>
    <div class="box bs"><div class="lbl">풀이 (b) — 역변환으로 균등분포 복원</div>
      <p>X = (1/π)arctan(Y)이면 역함수 Y = tan(πX). 단조변환 공식 적용:</p>
      <div class="mb">\[ f_X(x)=f_Y(\tan\pi x)\cdot|\pi\sec^2(\pi x)|=\frac{1}{\pi(1+\tan^2\pi x)}\cdot\pi\sec^2(\pi x)=1 \]</div>
      <p>1+tan²(θ) = sec²(θ)이므로 분자분모가 소거되어 f_X(x) = 1. X ~ Uniform(−1/2,1/2) 확인!</p>
    </div>
    <div class="box bt"><div class="lbl">⭐ 시험 팁</div>
      <p>단조변환 공식 적용 단계: ① 역함수 구하기 → ② 역함수 도함수의 절댓값 계산 → ③ f_X에 역함수 대입 후 곱하기. arctan의 도함수 1/(1+y²)은 반드시 암기!</p>
    </div>
  </div>
</div>

<div class="ch"><h2>📙 문제집 6 풀이 (15문제)</h2><p>혼합 확률변수, 특수 분포, 결합분포, 공분산</p></div>

<!-- P6-1 -->
<div class="pc" id="p61">
  <div class="ph"><div class="pn">1</div><div><div class="pt">은행 — 혼합 확률변수의 CDF</div><div class="ps">전체 확률 정리로 조건별 분해</div></div></div>
  <div class="pb">
    <div class="box bc"><div class="lbl">핵심 개념: 전체 확률 정리</div>
      <div class="mb">\[ F_X(x)=P(N=0)\cdot P(X\le x\mid N=0)+P(N=1)\cdot P(X\le x\mid N=1) \]</div>
    </div>
    <div class="box bs"><div class="lbl">풀이</div>
      <p>P(N=0) = P(N=1) = 1/2. x ≥ 0에서:</p>
      <ul>
        <li>N=0이면 대기 없음: P(X≤x|N=0) = 1</li>
        <li>N=1이면 X~Exp(λ): P(X≤x|N=1) = 1−e^{−λx}</li>
      </ul>
      <div class="mb">\[ F_X(x)=\frac{1}{2}\cdot1+\frac{1}{2}(1-e^{-\lambda x})=1-\frac{1}{2}e^{-\lambda x},\quad x\ge0 \]</div>
      <p>x=0에서 점프 크기 = 1/2 → P(X=0) = 1/2 (대기 없이 바로 서비스)</p>
    </div>
    <div class="box bt"><div class="lbl">⭐ 시험 팁</div>
      <p>혼합 확률변수 CDF는 <strong>전체 확률 정리로 분해</strong>합니다. CDF에 점프가 있으면 그 점프 크기 = 이산 성분의 확률.</p>
    </div>
  </div>
</div>

<!-- P6-2 -->
<div class="pc" id="p62">
  <div class="ph"><div class="pn">2</div><div><div class="pt">Al의 택시/버스 대기</div><div class="ps">복잡한 혼합 확률변수 — 이산+연속 분해</div></div></div>
  <div class="pb">
    <div class="box bc"><div class="lbl">상황 분석</div>
      <ul>
        <li>P(택시 대기 중) = 2/3 → 즉시 탑승 (대기 = 0)</li>
        <li>P(기다려야 함) = 1/3:
          <ul>
            <li>택시가 5분 후 도착 (P=1/2): 버스(5분) 탑승 → 대기 = 5</li>
            <li>택시가 5분 내 도착 (P=1/2): 택시 탑승 → 대기 Z ~ Uniform(0,5)</li>
          </ul>
        </li>
      </ul>
    </div>
    <div class="box bs"><div class="lbl">풀이</div>
      <p>이산 성분 A(대기=0 또는 대기=5)의 확률: P(A) = 2/3 + 1/3·1/2 = 5/6</p>
      <p>이산 성분 Y의 PMF: P(Y=0) = (2/3)/(5/6) = 4/5, P(Y=5) = (1/6)/(5/6) = 1/5</p>
      <p>연속 성분 Z ~ Uniform(0,5), P(연속) = 1−5/6 = 1/6</p>
      <div class="mb">\[ F_X(x)=\frac{5}{6}F_Y(x)+\frac{1}{6}F_Z(x)= \begin{cases}0 & x<0\\ \frac{2}{3}+\frac{x}{30} & 0\le x<5\\ 1 & x\ge5 \end{cases} \]</div>
      <div class="mb">\[ E[X]=\frac{5}{6}\!\left(\frac{1}{5}\cdot5\right)+\frac{1}{6}\cdot\frac{5}{2}=\frac{5}{6}+\frac{5}{12}=\frac{5}{4} \]</div>
    </div>
    <div class="box bt"><div class="lbl">⭐ 시험 팁</div>
      <p>혼합 RV: E[X] = P(이산)·E[이산] + P(연속)·E[연속]. 이산/연속 성분을 <strong>완전히 분리</strong>해서 생각하는 것이 핵심입니다.</p>
    </div>
  </div>
</div>

<!-- P6-3 -->
<div class="pc" id="p63">
  <div class="ph"><div class="pn">3</div><div><div class="pt">W = ((X−μ)/σ)² — 카이제곱(1) 분포</div><div class="ps">정규분포를 표준화 후 제곱 → 연쇄법칙 미분</div></div></div>
  <div class="pb">
    <div class="box bc"><div class="lbl">핵심 개념</div>
      <p>X~N(μ,σ²) → Z = (X−μ)/σ ~ N(0,1). W = Z²의 분포를 구합니다.</p>
      <p>결과: W ~ <strong>카이제곱 분포 χ²(1)</strong> = Gamma(1/2, 1/2).</p>
    </div>
    <div class="box bs"><div class="lbl">풀이</div>
      <p>w ≥ 0에서:</p>
      <div class="mb">\[ F_W(w)=P(Z^2\le w)=P(-\sqrt{w}\le Z\le\sqrt{w})=\int_{-\sqrt{w}}^{\sqrt{w}}\varphi(z)\,dz \]</div>
      <p>미분 (연쇄법칙 + 기본정리):</p>
      <div class="mb">\[ f_W(w)=\varphi(\sqrt{w})\cdot\frac{1}{2\sqrt{w}}+\varphi(-\sqrt{w})\cdot\frac{1}{2\sqrt{w}} \]</div>
      <p>φ(z)는 짝함수이므로 φ(−√w) = φ(√w):</p>
      <div class="mb">\[ f_W(w)=\frac{1}{\sqrt{w}}\varphi(\sqrt{w})=\frac{1}{\sqrt{2\pi w}}e^{-w/2},\quad w>0 \]</div>
    </div>
    <div class="box bt"><div class="lbl">⭐ 시험 팁</div>
      <p>CDF를 w로 미분할 때: d/dw[∫_{−√w}^{√w}φ(z)dz] = φ(√w)·(1/2√w) − φ(−√w)·(−1/2√w). <strong>φ가 짝함수</strong>여서 두 항이 더해짐을 기억하세요!</p>
    </div>
  </div>
</div>

<!-- P6-4 -->
<div class="pc" id="p64">
  <div class="ph"><div class="pn">4</div><div><div class="pt">로그정규분포의 적률</div><div class="ps">MGF를 이용해 E[Yⁿ]을 적분 없이 계산</div></div></div>
  <div class="pb">
    <div class="box bc"><div class="lbl">핵심 아이디어</div>
      <p>Y = eˣ이면 <span class="hl">E[Yⁿ] = E[eⁿˣ] = MGF of X evaluated at t=n</span>.</p>
      <p>정규분포 X~N(μ,σ²)의 MGF: M_X(t) = exp(μt + σ²t²/2)</p>
    </div>
    <div class="box bs"><div class="lbl">풀이</div>
      <div class="mb">\[ E[Y^n]=E[e^{nX}]=M_X(n)=\exp\!\left(\mu n+\frac{\sigma^2 n^2}{2}\right) \]</div>
      <p>n=1 (평균): \(\displaystyle E[Y]=e^{\mu+\sigma^2/2}\)</p>
      <p>n=2 (2차 적률): \(\displaystyle E[Y^2]=e^{2\mu+2\sigma^2}\)</p>
      <div class="mb">\[ \text{Var}(Y)=E[Y^2]-(E[Y])^2=e^{2\mu+2\sigma^2}-e^{2\mu+\sigma^2}=e^{2\mu+\sigma^2}(e^{\sigma^2}-1) \]</div>
    </div>
    <div class="box bt"><div class="lbl">⭐ 시험 팁</div>
      <p>로그정규분포 E[Yⁿ]는 MGF 하나로 모든 적률을 바로 구합니다. <strong>복잡한 적분을 피하는 우아한 방법!</strong></p>
    </div>
  </div>
</div>

<!-- P6-5 -->
<div class="pc" id="p65">
  <div class="ph"><div class="pn">5</div><div><div class="pt">포아송 과정 → 첫 도착 시간 T ~ Exp(λ)</div><div class="ps">{T &gt; t} = {N_t = 0} 로 변환</div></div></div>
  <div class="pb">
    <div class="box bc"><div class="lbl">핵심 논리</div>
      <p><span class="hl">"T &gt; t" ⟺ "시간 t까지 아무도 안 옴" ⟺ N_t = 0</span></p>
    </div>
    <div class="box bs"><div class="lbl">풀이</div>
      <div class="mb">\[ P(T>t)=P(N_t=0)=\frac{(\lambda t)^0 e^{-\lambda t}}{0!}=e^{-\lambda t} \]</div>
      <div class="mb">\[ F_T(t)=1-e^{-\lambda t},\quad f_T(t)=\lambda e^{-\lambda t} \implies \boxed{T\sim\text{Exp}(\lambda)} \]</div>
    </div>
    <div class="box bt"><div class="lbl">⭐ 시험 팁</div>
      <p>포아송 과정 핵심 관계: 도착 간격 ~ Exp(λ), k번째 도착 ~ Gamma(k,λ). 이 관계에서 모든 문제가 파생됩니다.</p>
    </div>
  </div>
</div>

<!-- P6-6 -->
<div class="pc" id="p66">
  <div class="ph"><div class="pn">6</div><div><div class="pt">지수분포 Exp(1) 성질 종합 증명</div><div class="ps">E[X], Var(X), MGF, Y=X/λ, 무기억성</div></div></div>
  <div class="pb">
    <div class="box bs"><div class="lbl">E[X], Var(X) — 부분적분</div>
      <div class="mb">\[ E[X]=\int_0^\infty xe^{-x}\,dx=\left[-xe^{-x}\right]_0^\infty+\int_0^\infty e^{-x}\,dx=0+1=1 \]</div>
      <div class="mb">\[ E[X^2]=\int_0^\infty x^2e^{-x}\,dx=2\int_0^\infty xe^{-x}\,dx=2 \implies \text{Var}(X)=2-1=1 \]</div>
    </div>
    <div class="box bs"><div class="lbl">MGF</div>
      <div class="mb">\[ M_X(t)=\int_0^\infty e^{tx}e^{-x}\,dx=\int_0^\infty e^{-(1-t)x}\,dx=\frac{1}{1-t},\quad t<1 \]</div>
    </div>
    <div class="box bs"><div class="lbl">Y = X/λ ~ Exp(λ) 증명</div>
      <div class="mb">\[ F_Y(y)=P(X/\lambda\le y)=P(X\le\lambda y)=1-e^{-\lambda y} \implies Y\sim\text{Exp}(\lambda) \]</div>
      <div class="mb">\[ E[Y]=\frac{1}{\lambda},\quad\text{Var}(Y)=\frac{1}{\lambda^2},\quad M_Y(t)=\frac{\lambda}{\lambda-t},\;t<\lambda \]</div>
    </div>
    <div class="box bs"><div class="lbl">무기억성 증명</div>
      <div class="mb">\[ P(X>s+t\mid X>t)=\frac{P(X>s+t)}{P(X>t)}=\frac{e^{-(s+t)}}{e^{-t}}=e^{-s}=P(X>s)\quad\checkmark \]</div>
    </div>
    <div class="box bt"><div class="lbl">⭐ 시험 팁</div>
      <p>지수분포는 연속 분포 중 <strong>유일하게 무기억성</strong>을 가집니다. 증명 흐름: P(A∩B)/P(B) = P(A)를 지수함수로 계산하면 됩니다.</p>
    </div>
  </div>
