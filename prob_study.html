CH 01

연속 확률변수

Definition 4.1.1

확률밀도함수 (PDF)

연속 확률변수 X는 음이 아닌 함수 fX가 존재해, 모든 a ≤ b에 대해 다음을 만족할 때 정의됩니다.

P(a ≤ X ≤ b) = ∫[a→b] f_X(x) dx
// PDF는 확률 자체가 아니라 "단위 길이당 확률 질량"
💡 직관

PDF 값 자체가 확률은 아닙니다. fX(x) · δ ≈ P(x ≤ X ≤ x+δ)처럼, 아주 짧은 구간의 확률을 근사할 때 씁니다. CDF를 x로 미분하면 PDF가 됩니다.

기본 성질

PDF 필수 조건

  • ①

    정규화: ∫₋∞^∞ f_X(x)dx = 1

  • ②

    점 확률 = 0: P(X = a) = 0

  • ③

    등가성: P(a≤X≤b) = P(a<X<b)

Theorem 4.1.1

CDF와 PDF의 관계

F_X(x) = ∫₋∞^x f_X(t) dt

dF_X/dx = f_X(x)

CDF를 미분하면 PDF, PDF를 적분하면 CDF

주요 분포 3가지

대표 연속 분포 비교

분포표기PDF의미
균등분포 Uniform(a,b) 1/(b−a) on [a,b] 구간 내 어디서나 같은 확률
지수분포 Exp(λ) λe^(−λx), x≥0 사건 발생까지의 대기 시간
가우시안 N(μ, σ²) (2πσ²)^(−½) exp{−(x−μ)²/2σ²} μ: 위치, σ: 퍼짐 정도
Theorem 4.2.3 — Jensen 부등식

볼록함수와 기댓값의 관계

함수 g가 볼록(convex)이면: E[g(X)] ≥ g(E[X])

함수 g가 오목(concave)이면: E[g(X)] ≤ g(E[X])

💡 예시

g(x) = x² (볼록) → E[X²] ≥ (E[X])² → Var(X) ≥ 0 임을 확인할 수 있음.
대수의 법칙 증명에서 E|X₁−μ|² 의 제곱 ≤ E|X₁−μ|⁴ 를 보일 때 사용됩니다.

CH 02

변수변환 (Change of Variable)

Theorem 4.1.2 (핵심)

1변수 변환 공식

X의 PDF가 fX이고 Y = φ(X)로 변환할 때, φ가 미분가능하고 φ'이 연속·비영이면:

f_Y(y) = f_X(φ⁻¹(y)) · |dφ⁻¹/dy|
= f_X(φ⁻¹(y)) · |1 / φ'(φ⁻¹(y))|
💡 핵심 아이디어

역함수 정리(Inverse Function Theorem)를 이용해서 |dφ⁻¹/dy| = |1/φ'(x)|임을 보입니다. φ'>0이면 단조증가, φ'<0이면 단조감소 각각 다르게 CDF를 다룬 뒤 미분합니다.

증명 핵심 흐름

① CDF 구하기: φ' > 0이면 F_Y(y) = P(Y≤y) = P(X≤φ⁻¹(y)) = (F_X∘φ⁻¹)(y)
② φ' < 0이면 F_Y(y) = 1 − (F_X∘φ⁻¹)(y)
③ 미분 → chain rule + 역함수 정리 → 위 공식 도출

Theorem 4.1.3

확률 적분 변환 (Probability Integral Transform)

X의 CDF FX가 연속이고 순증가이면:

Y = F_X(X) ~ Uniform(0,1) // CDF로 변환하면 균등분포
F_X⁻¹(U) ≅ X, U ~ Uniform(0,1) // 역변환으로 샘플링 가능
💡 응용

이 정리를 이용하면 어떤 분포에서든 샘플링이 가능합니다. 균등분포 난수 u를 생성 → F_X⁻¹(u) 계산 → X의 샘플 획득. Box-Muller 변환도 이 원리 기반.

Theorem 4.1.4

비단조 함수의 변환

φ가 단조가 아닐 경우 (예: Y = X²), 구간을 분할해서 각 단조 구간의 역함수를 합산합니다.

f_Y(y) = Σᵢ f_X(φᵢ⁻¹(y)) · |1/φᵢ'(φᵢ⁻¹(y))|

예: Y = X²일 때 x>0 구간과 x<0 구간으로 분할하여:

f_Y(y) = f_X(√y)·(1/2√y) + f_X(−√y)·(1/2√y) (y > 0)
Theorem 5.3.1 — 이변수 변환

다변수 변환과 야코비안

(X₁, X₂) → (Y₁, Y₂) = (φ₁(X₁,X₂), φ₂(X₁,X₂)) 변환 시:

f_{Y₁,Y₂}(y₁,y₂) = f_{X₁,X₂}(φ₁⁻¹(y₁,y₂), φ₂⁻¹(y₁,y₂)) · |J(y₁,y₂)|

J(y₁,y₂) = det(∂φᵢ/∂yⱼ) // 야코비안 행렬식
💡 Box-Muller 변환

U₁, U₂ ~ Uniform(0,1) 독립일 때:
Z₀ = √(−2 ln U₁) cos(2πU₂) ~ N(0,1)
Z₁ = √(−2 ln U₁) sin(2πU₂) ~ N(0,1)
이 변환이 야코비안을 통해 증명됩니다.

CH 03

결합분포 (Joint Distributions)

Definition 5.1.1

결합 PDF

두 연속 확률변수 X, Y에 대해 결합 PDF fX,Y는 다음을 만족합니다:

P((X,Y) ∈ A×B) = ∫_B ∫_A f_{X,Y}(x,y) dx dy

∫_ℝ ∫_ℝ f_{X,Y}(x,y) dx dy = 1 // 전체 합 = 1
Definition 5.1.2

결합 CDF

F_{X,Y}(x,y) = P(X≤x, Y≤y)
= ∫₋∞^y ∫₋∞^x f_{X,Y}(s,t) ds dt

반대로 2차 편미분하면 PDF 복원:

f_{X,Y}(x,y) = ∂²F_{X,Y}/∂x∂y
Theorem 5.1.1 — 주변화

Marginalization

결합 PDF로부터 각 변수의 PDF 도출:

f_X(x) = ∫_ℝ f_{X,Y}(x,y) dy

f_Y(y) = ∫_ℝ f_{X,Y}(x,y) dx

나머지 변수를 전체 범위에서 적분으로 소거

CH 04

독립성 & 기댓값 분리

Definition 5.2.1 + Theorem 5.2.1

연속 확률변수의 독립

X와 Y가 독립 ⟺ 결합 CDF가 주변 CDF의 곱:

F_{X,Y}(x,y) = F_X(x) · F_Y(y)

더 편리한 동치 조건 (Theorem 5.2.1):

f_{X,Y}(x,y) = f_X(x) · f_Y(y) // 모든 x, y에서
💡 실용 팁 — Theorem 5.2.2

결합 지지 영역이 직사각형이고 f_{X,Y}(x,y) = g(x)·h(y) 형태로 인수분해되면 → X와 Y는 독립 (g, h가 정확한 PDF일 필요 없음!)

Theorem 5.4.3

독립 시 기댓값 분리

E[XY] = E[X] · E[Y]
E[f(X)·g(Y)] = E[f(X)] · E[g(Y)]

독립이면 함수를 취해도 독립이 유지됩니다. 이는 공분산 = 0으로 이어집니다.

Theorem 5.4.3 — 분리 가능한 MGF

독립일 때 결합 MGF

X₁, …, Xₙ이 독립이면 결합 MGF는 각 MGF의 곱:

M_X(t) = ∏ᵢ M_{Xᵢ}(tᵢ)

이 성질을 이용하면 독립 확률변수의 합의 분포를 쉽게 구할 수 있습니다.

CH 05

합성곱 (Convolution)

Theorem 5.2.3

독립 확률변수의 합

X₁, X₂가 독립이고 Y = X₁ + X₂이면 Y의 PDF는 합성곱:

f_Y(y) = (f_{X₁} * f_{X₂})(y) = ∫₋∞^∞ f_{X₁}(y−x₂) f_{X₂}(x₂) dx₂
유도 과정

① CDF: F_Y(y) = P(X₁+X₂ ≤ y) = ∫∫_{x₁+x₂≤y} f_{X₁}f_{X₂} dx₁dx₂
② y로 미분 → PDF 획득 (Leibniz 적분 미분)

합성곱의 현실 응용

왜 중요한가?

분야활용 예시
이미지 처리블러, 엠보스, 외곽선 검출 등 커널 연산
딥러닝CNN의 Convolutional Layer 이론적 근거
금융자산 가격 시뮬레이션, 손실 모델

CH 06

공분산 & 모멘트 생성함수

Definition 5.4.1

공분산 (Covariance)

Cov(X,Y) = E[(X−E[X])(Y−E[Y])]
= E[XY] − E[X]E[Y]
💡 해석

Cov > 0: X 증가 → Y 증가 경향 / Cov < 0: 반대 방향 / Cov = 0: 선형 무관 (독립은 아닐 수 있음)

Theorem 5.4.2

공분산 성질 (쌍선형)

Cov(aX+Z, bY+c)
= ab·Cov(X,Y) + b·Cov(Z,Y)

대칭성: Cov(X,Y) = Cov(Y,X)

Cov(X,X) = Var(X)

Definition 5.4.2

결합 MGF

M_X(t) = E[e^{t^T X}]
= E[exp(Σᵢ tᵢXᵢ)]

독립이면 M_X(t) = ∏ᵢ M_{Xᵢ}(tᵢ)

CH 07

강대수의 법칙 (Strong LLN)

Theorem 7.7 — Strong Law of Large Numbers

정리 (강대수의 법칙)

X₁, X₂, … 가 i.i.d., E[Xᵢ] = μ, E|Xᵢ|⁴ < ∞ 이면:

P( lim_{n→∞} X̄_n = μ ) = 1

X̄_n = (1/n) Σᵢ Xᵢ // 표본평균
💡 "강" vs "약" 의미

약대수의 법칙은 확률 수렴(P(|X̄ₙ−μ|>ε)→0), 강대수의 법칙은 거의 확실한 수렴(P(lim X̄ₙ=μ)=1). 강한 버전이 더 강력한 조건을 보장합니다.

증명 전략 (Analytic Proof)

4단계 증명 흐름

  • 1

    E|X̄ₙ−μ|⁴ 계산: 독립성을 이용해 교차항을 소거하면 E|X̄ₙ−μ|⁴ ≤ 3/n² · E|X₁−μ|⁴

  • 2

    마르코프 부등식 적용: P(|X̄ₙ−μ| ≥ ε) ≤ E|X̄ₙ−μ|⁴ / ε⁴ ≤ 3E|X₁−μ|⁴ / (n²ε⁴)

  • 3

    급수 수렴 확인: Σ P(|X̄ₙ−μ| ≥ ε) ≤ (3E|X₁−μ|⁴/ε⁴) · Σ 1/n² < ∞

  • 4

    보렐-칸텔리 보조정리 적용: 급수가 수렴 → P(|X̄ₙ−μ| ≥ ε i.o.) = 0 → 거의 확실 수렴 증명 완료

Jensen 부등식의 역할

증명 중간에 (E|X₁−μ|²)² ≤ E|X₁−μ|⁴를 이용합니다. 이는 φ(x) = x²이 볼록함수이므로 Jensen 부등식에서 직접 나옵니다.

Borel-Cantelli Lemma (Theorem 7.6)

보렐-칸텔리 보조정리

사건열 A₁, A₂, … 에 대해:

Σ P(Aₙ) < ∞ ⟹ P(Aₙ i.o.) = 0

"i.o. (infinitely often)" = "무한히 자주 일어남" = ∩_N ∪_{n≥N} Aₙ

💡 해석

확률의 합이 유한하면, 해당 사건은 유한 번만 일어납니다 (거의 확실하게). 강대수의 법칙 증명의 핵심 도구입니다.
